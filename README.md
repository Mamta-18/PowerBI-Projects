# Power BI Projects 📊

Welcome to my **Power BI Projects Repository** 🚀  
This repository contains interactive and business-oriented Power BI dashboard projects developed using **Power BI, Power Query, DAX, and Data Modeling** techniques.

The goal of these projects is to transform raw datasets into meaningful business insights through professional dashboards and data storytelling.

- Insurance claim analysis
- Customer demographic insights
- Premium and policy analysis
- Revenue and claim trends
- Interactive KPI dashboards
- Data-driven business insights

### 🔹 Key Features
- Ride booking analysis
- Revenue analysis

## 3️⃣ Myntra Sales Performance Dashboard 🛍️📈

An interactive Power BI dashboard designed to analyze Myntra's sales performance, customer purchasing behavior, product trends, and overall business performance. The dashboard provides actionable insights to support data-driven business decisions.

### 🔹 Key Features
- Monitor overall sales performance
- Analyze customer purchasing behavior
- Identify top-performing brands and categories
- Track order fulfillment performance
- Understand regional sales distribution
- Support data-driven decision making
